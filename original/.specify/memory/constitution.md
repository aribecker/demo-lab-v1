# Hello Full Stack Constitution

## Core Principles
1. **Specification First** — User-visible behavior MUST be specified before implementation.
2. **Small, Understandable Stack** — Prefer platform capabilities and minimal dependencies for this demonstration.
3. **Testable Contracts** — API behavior and success criteria MUST be objectively verifiable.
4. **Separation of Concerns** — Browser UI and server API remain distinct layers.
5. **Reproducible Build** — A clean checkout MUST run with documented commands.

## Quality Gates
- `npm run build` MUST pass before execution.
- `npm test` MUST verify the API contract.
- No generated dependency folders are stored in the source repository.
